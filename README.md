# TrazabilidadCafé · Interfaz web de consulta y registro

Aplicación web (HTML, CSS y JavaScript sin frameworks) para consultar el historial de lotes de café
mediante un código QR y registrar lotes y eventos con las mismas reglas del contrato inteligente
`TrazabilidadCafe.sol` del trabajo del curso de Blockchain.

> Proyecto final del curso de Desarrollo Front-End 2026-2. Todos los datos son **ficticios**.
